# 教學進度追蹤

純前端的教學進度追蹤 PWA：原定課節表 vs 實際教學進度、測驗／功課待辦、代印工作紙花費記錄、跨班對照。

**這個 repo 是公開的通用模板，不含任何學校、教師、班別、課表資料。**
你的課表（班別、原定進度、校曆）存在你自己的私有 GitHub Gist（`plan.json`）；
你平常記的實際進度、備註另外存在另一個私有 Gist（`progress.json`）。
兩份資料都只在你自己帳號底下，這個公開的程式碼 repo 完全看不到。

---

## 快速開始

**想讓 Claude／AI agent 幫你做完整套設定**：把 [`SETUP_PROMPT.md`](./SETUP_PROMPT.md) 整段複製給它，
連同你的課表來源檔案（Excel/PDF/課表照片皆可）。它會依序：讀懂你的課表、產生 `plan.json`、
幫你部署到 GitHub Pages、建立私有 Gist、教你填設定。

**想自己手動做**：見下面「一、部署」「二、設定課表資料」「三、開啟同步」，
或直接看 [`SETUP_PROMPT.md`](./SETUP_PROMPT.md) 最後「如果你想自己手動做」那段的精簡步驟。

---

## 一、部署

1. Fork 這個 repo（或用網頁 Upload files 把檔案複製到你自己新建的 **public** repo）
2. repo → **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)` → Save
3. 一兩分鐘後開 `https://<你的帳號>.github.io/<repo 名稱>/`

手機開同一個網址，Safari「加入主畫面」或 Chrome「安裝應用程式」就會變成 app 圖示，離線也開得到。

## 二、設定課表資料

App 第一次開啟、還沒設定課表時，會顯示「還沒有課程設定」的畫面，引導你去做這步。

課表資料的完整格式見 [`PLAN_SCHEMA.md`](./PLAN_SCHEMA.md)。
最簡單的做法是把你的課節表來源交給 Claude，照 `SETUP_PROMPT.md` 幫你產生 `plan.json`
並建立一個私有 Gist（`gh gist create` 或網頁 gist.github.com 手動建立都可以，記得選 **secret**）。

## 三、開啟同步（第一次做一次就夠）

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token
2. 只勾 **`gist`** 一項，有效期揀 No expiration
3. 回到工具，右上角「設定」：
   - 貼上 token
   - 「課程設定 Gist ID」貼上第二步建立的那個私有 Gist 的 ID
   - 「進度記錄 Gist ID」留空——第一次存檔會自動幫你建一個新的私有 Gist 存放你之後的實際記錄
4. 按「儲存並同步」

換另一部電腦或手機：一樣貼 token，兩個 Gist ID 都填上（進度記錄 Gist ID 在設定畫面看得到，
或 GitHub → 你的 Gists 裡面找 `progress.json`），之後幾邊就同一份記錄。

> Token 和兩個 Gist ID 只存在該部裝置的瀏覽器 localStorage，不會進 repo，也不會出現在網址。
> 沒設定 token 就沒辦法讀到課表（課表本來就存在 Gist，不在 repo 裡）；
> 但設定好課程設定 Gist 之後，實際記錄沒設定同步也能先用，只是記錄只留在該部瀏覽器，換裝置拿不到。

## 四、怎樣用

| 分頁 | 做什麼 |
|---|---|
| **今日** | 今天要上的課、各班下一節、以及**過去未記錄**的課節（補記錄用） |
| **月曆** | 整個月的格狀日曆。每一節課是一張卡，上半是原定內容、下半是你輸入的實際進度，右上角一個狀態符號。右上可切「月／週」，上面一排檔案夾樣式分頁可切班別／合併群組（有設定的話） |
| **測驗・功課** | 從原定進度自動抽出的測驗、統測、堂課、功課、工作紙、實驗，逐項打勾 |
| **代印** | 記錄代各班影印工作紙的花費，學期末跟班上收錢用 |
| **總覽對照** | 各班＋合併群組並排比較、落後節數、匯出（跨班逐節清單也在這裡的對照表） |

**代印怎樣用**：上面填一筆——日期、班別、印了什麼、張數（每份幾張紙）、份數、黑白／彩色、單／雙面、備註，按「加入記錄」。
金額照 `plan.json` 裡設定的 `printRate` 自動算（單面價，雙面雙倍，張數×份數×單價）；沒設定單價的話金額全部是 $0，記錄功能照樣能用。
「各班應收」表按班別列出合計，方便學期末跟催；收到錢之後直接把該筆記錄刪掉即可，不另外標記已收。
「匯出 CSV」可以印出來或給班代核對明細。

**月曆怎樣用**

每張課堂卡分兩區：

- 上半 = 原定內容（灰底斜體），**雙擊**可以就地改，改了會蓋過課節表的版本，清空即還原
- 下半 = 實際進度（白底粗體，跟上半明顯分開），**雙擊**就地輸入。Enter 儲存，Shift+Enter 換行，Esc 取消

右上角三個小符號 `✓`／`–`／`✕`（已上／部分／停課）**直接按**就設定，不用開視窗、也不是循環的；
按已經選中的那個會取消變回未記錄。
過了日子還沒記錄的，卡片上方那條會轉橘色提醒你補。

格子裡每一節都會列出來，不會省略；按日期數字還可以在下面展開一張完整清單，可以寫備註。
手機上月曆可以左右滑動，其餘一樣。

**加開課節**：日期格下面有「＋加課」（展開後的日期詳情上面是「＋加開課節」），
按了選班別、節次（可留空）、內容，就會多一節正常課節出來——可以記錄狀態、算進進度、
匯出 CSV 也會有。這種課節標「加開」，在「編輯」視窗裡可以整節刪掉（原定課節表裡的課不能刪，只能改內容或標停課）。

**顏色**：每班一個顏色，`plan.json` 的 `colors` 裡指定；沒指定的話自動配色（CVD 友善色盤，
按班別出現順序分配）。每張卡都有班名，不會只靠顏色分辨。

**分頁怎樣切**：月曆上方是檔案夾樣式的分頁列，最左邊「總」看全部班別。
如果 `plan.json` 有設定 `groups`（合併群組），後面會照設定分組列出（用小間隔分開），
按群組本身那個分頁看該群組所有班的課節疊在一起；「總覽對照」表頭的合併列也是同一組數字。
沒設定 `groups` 的話就只有「總」和各班，沒有合併分組。

**記錄一節課**：也可以在清單按「記錄」循環狀態，或按「編輯」開視窗一次寫齊實際內容、備註和原定修改。

**進度指標**：`差 = 已上節數 − 到今天為止應上的節數`。
`✓` 算一節、`–` 算半節、`✕` 不計入應上。所以停課記下來，指標才準。

**原定內容改了**：月曆上半格雙擊，或在「編輯」視窗的「修改原定內容」改，留空即還原。

## 五、之後要更新課表

學期中課表有變動、或者要把原本粗略推算的內容補細，把新的來源檔案給 Claude，
請它照 [`PLAN_SCHEMA.md`](./PLAN_SCHEMA.md) 重新產生 `plan.json`，
更新你自己那個「課程設定」私有 Gist 的內容就好（不用碰這個公開 repo）。
**你平常記的實際進度存在另一個 Gist，不會被覆蓋。**

## 六、給其他老師用

這個 repo 本身就是通用模板，程式碼裡不含任何人的課表資料。
別人要用的話，直接照 [`SETUP_PROMPT.md`](./SETUP_PROMPT.md) 走一次自己的設定流程即可，
不需要動到你的 repo 或你的 Gist，彼此完全獨立。
